\## What We Did



In the first lecture, we started with an overview of the course, including the course outline and what we would be learning throughout the semester. We then started with the basics of computer graphics.



One of the first things we discussed was how graphics are actually made. A screen is made up of pixels, and pixels are the basic units that allow us to display an image. From these basic points, we can start drawing things. Points can be connected to make lines, and lines can be combined to create 2D shapes.



We then discussed curves, which I found particularly interesting. Curves are important in graphics because they allow us to represent smooth shapes instead of only using straight lines and basic geometric shapes. Curves are also common in nature, where many objects and forms are not made up of perfectly straight lines.



Another interesting point was that smooth curves are predictable and can be analyzed mathematically. This connects computer graphics with concepts from calculus, since we can use mathematics to study and work with curves, make calculations, and even make predictions about their behavior.



Overall, the first lecture helped me understand that computer graphics is not simply about drawing things on a screen. It starts from very basic concepts such as points and pixels and gradually builds towards more complex shapes and curves using mathematical ideas.
